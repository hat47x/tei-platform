# reference-table-definition-document（#1803）

受理済みの意味から、表定義書（Markdown）を導出する参照です。設計者やレビュー者が読む成果物を作ります。Workspaceは変更しません。

~~~text
go run ./tools/reference-table-definition-document/cmd/tei-table-definition-document \
  -workspace reference/workspace -out /tmp/table-definitions.md
~~~

出力先のファイルが既にある場合は失敗します。標準出力には、構造の版、文書のdigest、未解決の事項を出します。

## 文書の内容

Dataごとに、属性（型、物理列、格納型、NULL）、候補キー、関数従属性、関連、物理表（主キー、一意制約、外部キー）を載せます。

## 守っている境界

- 文書の冒頭に、導出元の構造の版を記録します。同じ版からは同じ内容が得られます。
- 文書の編集は、意味の正本へ戻しません。冒頭にその旨を記します。
- 業務上の識別（候補キー）と、物理表の主キーを別の節に分けて載せます。
- 定義されていない型、存在しない関連先、存在しないDataへの物理対応は、未解決の事項として載せます。補完も省略もしません。
- 物理表への対応がないDataは、その旨を明記します。

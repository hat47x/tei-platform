# 変換エンジンの実構築と出力確認

`main.go`は、固定したソースとGo構築器から変換エンジンを二回構築し、実成果物と構築証拠を照合する参照実装である。出力先を指定する場合はリポジトリ外に限り、既存の出力を置換しない。

## 検証入口

リポジトリのGo版、Bash、Python 3、GNUの`sha256sum`と`stat`があるLinux環境で、ルートから実行する。対象コミットを完全なSHAで指定し、追跡・未追跡・無視ファイルがないクリーンなチェックアウトを使う。

```bash
bash tools/reference-transform-runtime-engine-build/verify-export.sh EXACT_HEAD
```

個別試験に続き、実成果物の出力、証拠の対象版と実バイト列の一致、同じ出力先への再実行拒否、既存の内容・権限モードの保持、同じ実行ファイルの応答、一時公開ファイルの回収を確認する。出力確認用のディレクトリはリポジトリ外に一時作成し、終了時に回収する。

成功時は既存のビルド証拠JSONを標準出力へ返す。新しい証拠形式や実行権限を追加しない。候補SHA、Go版、実行前後のクリーン状態は標準エラーへ出す。失敗時は終了値を非ゼロとし、成功結果を返さない。個別確認の条件は[課題 #1100](https://github.com/hat47x/tei-platform/issues/1100)を参照する。

## 判定の範囲

このスクリプトは実出力の確認であり、全体健全性検証は別に実行する。同じ対象コミットで`bash tools/repository-health-check.sh`を省略せず実行し、対象mainと候補が変わっていないことを確かめてから資格を判定する。記録と申し送りはIssueへ記載する。

実出力の成功を、正式な証明発行者、実行の現在権限、本番配備、すべてのファイルシステムでの成立の根拠にしない。

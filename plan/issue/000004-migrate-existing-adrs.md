# ISSUE-000004: 既存ADRを`plan/adr`へ段階的に移行する

- 状態: 完了

## 背景

ADR-0016で、上位・横断的なADRを`plan/adr/`へ置く方針を採用しました。

移行開始時点ではADR-0001〜0015が`docs/adr/`を正本としており、多数の既存リンクと過去の文脈を壊さずに保存場所を統一する必要がありました。また、移行中に同じADR番号を別の意味で再利用すると判断履歴が曖昧になるため、番号は振り直さず、ADR-0016以降も同じ連番を継続する方針としました。

## 関連するProduct Requirement

- RQ-021 Reference / Conformance
- RQ-022 実装済み範囲と設計上の主張の区別

## 移行結果

ADRの正規保存場所は`plan/adr/`へ統一しました。

- ADR-0001〜0015の本文を番号・意味を変えず`plan/adr/`へ移行
- ADR-0016以降も`plan/adr/`で連番を継続
- `plan/adr/README.md`を現在の判断履歴の一覧と正規入口に設定
- `docs/adr/0001`〜`0015`は本文を持たない互換案内へ置換
- `docs/adr/README.md`は旧URLからの互換入口として維持
- `docs/adr/`へ新しいADRを追加しないことを明示

`docs/adr/`と`plan/adr/`を二重正本にはしません。設計判断の本文は`plan/adr/`だけを正本とし、`docs/adr/`は過去のURLや文書からの導線だけを担います。

## 互換入口を残す判断

`docs/adr/README.md`とADR-0001〜0015の案内ファイルは、移行途中の一時的な本文コピーではありません。既存リンクを壊さず正本へ誘導するための小さい互換層として残します。

将来この互換層を削除する場合は、本Issueの未完了作業として扱わず、既存参照への影響を確認した別判断として行います。

## 制約の確認

- ADR番号は振り直していない
- 移行のために既存ADRの意味を変更していない
- 同じ番号の異なる判断を新旧パスへ置いていない
- 新規ADRは`plan/adr/`だけへ追加する
- ADR-0001以降を`plan/adr/README.md`から一続きの判断履歴として追跡できる

## 完了条件

- [x] ADR-0001〜0015の正本を`plan/adr/`へ移した
- [x] 既存ADR番号を維持した
- [x] ADR-0016以降を同じ連番で継続した
- [x] `docs/adr/`を本文の第二正本ではなく互換案内へした
- [x] `docs/adr/README.md`の役割を互換入口として確定した
- [x] `plan/adr/README.md`を現在の正規一覧とした
- [x] 新規ADRの保存先を`plan/adr/`へ一本化した

ADR-0001以降を一つの連続した判断履歴として追跡でき、現在の正規保存場所が`plan/adr/`であることをRepository内から確認できるため、本Issueは完了とします。

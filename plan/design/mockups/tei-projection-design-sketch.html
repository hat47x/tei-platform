TEI — First Web Target / Editor Projection

同じCanonicalな意味を、二つのProjectionへ

TEIが利用者と開発者へ向ける面を、15のフレームとして描いたスケッチです。第一Web Target、Editor、既存認証、Database Workbench、 Gate Evidence、Runtime観測、CLI、同時編集、キーボード操作、そしてCoreとプラグインの拡張境界まで、意味・実現・実行結果・観測結果の境界が画面上でも保たれるかを確かめるために描きました。 業務端末（1280〜1920、キーボード中心）を前提とし、既定のUIはプラグインでカスタムされるものとして、静的モックで描いています。

状態: 評価待ち / 未採用 対象: ISSUE-000007 / 000008 / 000046 RQ-010 / 011 / 013 / 018 / 021 前提: Gate B Not Ready

この文書の位置づけ

実装物ではなく、決定前の視覚化です。ここに描いた画面はまだ採用されていません。

これは何か。 Application Driverまでで成立している意味境界を、Webの画面とEditorの画面に写すとどう見えるかのスケッチです。 Gate BはNot Readyで、Handover Baseline B も未固定です。したがってここでの画面は 実装の根拠にはならず、決定すべき論点を目に見える形にするための材料です。数値と名前はReference Workspaceの実データに合わせていますが、 行の値はサンプルです。
方向性（仮置き）。 「計器盤」— 業務端末として一画面の情報密度を優先し、装飾より状態の可読性を採ります。 Canonical IDは常に等幅で併記し、意味の出所を隠しません。既存のブランド資産・デザインシステムはRepository内に無いことを確認したうえでの選択です （*.css / *.tsx / tokens.* / tailwind.config.* はいずれも0件）。配色は緑青（#2f7d6b）と青銅（#8a6a2f）を軸にしています。

決まったこと

2026-09-06に確認した前提です。以降のスケッチはこれに従います。

利用環境は業務端末

1280〜1920のデスクトップ、キーボード中心。Frame 11の操作体系とFrame 13の折り畳みはこの前提から描いています。モバイルは第一Targetの範囲に入れません。

移行元は一般的なローコード開発ツール

特定製品の画面を再現するのではなく、利用者が持っている語彙とTEIの置き場所の対応をFrame 12で示します。対応しないものも同じ面に並べます。

Editorは複数人での同時編集を視野に入れる

排他ロックを作り込まず、presenceの表示と受理時の突き合わせで扱います（Frame 10）。履歴はGitへ委ね、Editor内に第二の履歴を持ちません。

当面は静的モックのまま画面数を増やす

クリックで動く試作へは進めません。Gate CのInteraction / Functional Evidenceをどう取るかは別途決めます。

UIを含む物理レイヤーはプラグインで実現する

Driverのコアは必要最小限のメタ制御に留め、Editor / Driver間の挙動は動的に拡張できるものとします。既定のEditorはカスタムされる前提で、UI提供もプラグインの一種として扱います（Frame 14・15）。プラグイン体系そのものは別途整理中です。

引き継ぐべきキー割り当ては無い

既存システム側の制約がないため、Frame 11の割り当てはこちらの既定として決めます。制約はブラウザ・OSとの衝突回避と、Coreの予約キーをプラグインが奪わないことです。

まだ聞けていないこと

Repository内の情報からは決められない項目です。

ブランド・視覚要素の制約

TEIとして使う配色・ロゴ・書体の指定はありますか。無ければ今回の「計器盤」方向で進めます。

Repository内にデザイン資産が無いため、現在は仮置きです。

UI提供プラグインの実行形態

描画を担うプラグインを、in-process・別プロセス・ブラウザ内のどれで動かす想定か。整理中のプラグイン体系が決まった時点で、Frame 14・15の権限とsandboxの表現を合わせます。

実行形態によって、渡せるデータの粒度と権限の既定が変わります。

評価待ちのスケッチです。採用されるまで実装やReference変更の根拠にはしません。画面内の受注データはサンプルで、Canonical ID・Pattern・Validation・Contract Queryの名称はReference Workspaceの実定義に一致させています。

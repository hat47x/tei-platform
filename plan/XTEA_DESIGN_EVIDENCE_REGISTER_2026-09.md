# External Design Reference Note

This path is retained temporarily for existing links.

Detailed third-party comparison is not part of TEI's public specification. External material may inform questions during design work, but accepted TEI behavior is supported by TEI-local Requirements, Architecture, Reference results, ADRs, implementation, and Evidence.

Public documentation should identify an external source only when it materially helps the reader understand a TEI decision. Otherwise, describe the TEI requirement directly.

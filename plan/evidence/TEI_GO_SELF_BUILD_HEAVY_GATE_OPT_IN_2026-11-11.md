# 重い観測は、既定の試験から外す（§4.51）

§4.50で`./cmd/tei`の全鎖を回帰試験に載せました。**それは「セルフビルドが実現した」と言うための唯一の観測**です。しかし**`go test ./...`の既定に約4分を足す**ことは、日常の検証を鈍らせます。

## 決めたこと

**環境変数 `TEI_SELF_BUILD_FULL_CHAIN=1` を設定したときだけ走ります。**

| 指定 | 挙動 |
| --- | --- |
| 未設定 | **skip**（理由を表示） |
| `TEI_SELF_BUILD_FULL_CHAIN=1` | 実行 |

## なぜ `-short` ではないか

**`-short` は「速くしたい呼び手」の合図**であり、`go test ./...` は既定で `-short` を付けません。**既定の `./...` に4分が乗る**のを避けたいので、**観測ごとに明示的に選ぶ**形にしました。

**これは観測を弱めるのではありません。** 実行する手段があり、**その手段で通ることを実測しました**。

## 実測

| 指定 | 結果 |
| --- | --- |
| 未設定 | **SKIP**（0.00秒・理由を表示） |
| `TEI_SELF_BUILD_FULL_CHAIN=1` | **PASS**（**980秒**。前回は254秒で、負荷により変動） |

環境：WSL2 Ubuntu 22.04、`go1.27.3 linux/amd64`。

## 言っていないこと

- **CI でこの試験を回すこと**。今の `repository-health` は `go test ./...` を実行するので、**環境変数を設定しない限り skip** されます。回すかどうかは別の判断です
- 実行時間の安定（**254秒〜980秒の幅**があり、ホストの負荷に依存）

## 検証

- 上の表のとおり
- `gofmt` 差分なし／`go vet ./cmd/tei`：PASS

**NOT RUN**：`darwin`・`arm64`、CI。

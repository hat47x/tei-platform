# 準拠確認の資料

このディレクトリには、特定の実装版や変更時点で、設計上の条件が実装と検査にどう表れているかを説明する資料を置きます。各資料は対象範囲と確認方法を記し、コードや自動検査へたどれるようにします。

ここにある説明だけで、現在の実装状態や本番環境での動作を保証することはできません。現在の状態は[実装状況](../status.md)で確認し、実際の判定には対象の変更版と検査結果を結び付けてください。

新しい変更で満たす条件、受入基準、検査の手順は[`plan/gate/`](../../plan/gate/README.md)に置きます。採用前の案や複数作業にまたがる機能設計は[`plan/design/`](../../plan/design/README.md)に置きます。実装の準拠説明を計画へ複製せず、計画上の条件を確認済みの事実として記述しません。

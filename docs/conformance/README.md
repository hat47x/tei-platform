# 準拠確認の資料

このディレクトリには、特定の実装版や変更時点について、設計上の条件と実装・検査との対応を説明する資料を置きます。それぞれの資料で対象範囲と確認方法を示し、対応するコードや自動検査を追跡できるようにします。

これらの説明だけでは、現在の実装状態や本番環境での動作は保証できません。現在の状態は[実装状況](../status.md)で確認してください。実際の判定では、対象とする改訂版と検査結果を結び付ける必要があります。

新たな変更に求める条件、受け入れ基準、検査手順は[`plan/gate/`](../../plan/gate/README.md)で管理します。採用前の案や、複数の作業にまたがる機能設計は[`plan/design/`](../../plan/design/README.md)で管理します。準拠確認の説明を計画文書へ重複して置いたり、計画上の条件を確認済みの事実として記したりはしません。

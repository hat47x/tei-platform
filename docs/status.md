# TEIの実装状況

- 整理日: 2026-10-12
- 開発段階: **参照実装を使った実験と検証**
- 品質に関する注意: **生成AIを用いて開発中であり、コード・設計・安全性の体系的な人的確認は未実施**です。本番利用を想定していません。

TEIは、ドメイン知識と技術を分けて管理するローコード開発基盤を目指しています。現在は業務システムを主な参照例とし、コマンドラインと参照用作業領域を使って、設計・実装・実行・観測のつながりを確かめています。現時点では、完成した製品、画面編集機能、汎用の実行基盤は提供していません。全体像は[README](../README.md)、価値と対象範囲は[製品が大切にする価値](../product/value/TEI_PRODUCT_VALUE.md)と[製品要求](../requirements/TEI_PRODUCT_REQUIREMENTS.md)を参照してください。

## 未完成または未検証のこと

- **統合モデラーと編集環境**: 人やAIの入力からデータ、機能、業務の三つの視点を一貫して編集・受理・実行する製品としては未完成です。
- **二つ目の実行先と多様な配備先**: 同じ業務定義から汎用ウェブ、デスクトップ、モバイル、組み込み機器、IoTを動かした製品上の検証根拠はありません。
- **外部接続と実際の提供元**: 参照実装で使う合成試験データと、Oracleなど実環境での認証、接続、操作の成立を区別します。未取得の検証根拠を成功として扱いません。
- **実行先での再現可能な操作**: 判定段階Cの初回結果と、後続のR7再実行・反復確認は別の検証です。未実施の確認も残っています。
- **安全性と品質**: 安全性、個人情報、第三者の素材の利用条件、権限設定に関する包括的な監査、体系的な人的確認、本番運用での耐久性・高可用性の確認は未完了です。
- **開発用CIと製品上の受入**: GitHub Actionsによるコードの全体検証は再開し、上記の特定コミットで成功しました。一方、未確認の改訂や別のプルリクエストまで自動的に合格とはなりません。CIには、初見の利用者による一巡、三視点の編集と再反映、実際のWeb操作・データベース保存・独立した読取りによる結果確認は含まれません。必要な製品実証は[要件の優先順位 #982](https://github.com/hat47x/tei-platform/issues/982)と[横断受入 #1119](https://github.com/hat47x/tei-platform/issues/1119)で追跡します。主ブランチの保護と必須チェックの設定も[課題 #1189](https://github.com/hat47x/tei-platform/issues/1189)で未完了です。

検証済みの実装と、まだ確定していない設計を区別して開発を進めます。優先順位は[TEIの全体計画](../plan/MASTER_PLAN.md)、技術上の境界は[全体構成](architecture.md)、業務設計の考え方は[業務システム設計](business-system-design.md)を参照してください。

## 最初に動かす

Goの開発環境で行う主なローカル確認は、次のとおりです。

```bash
go test ./...
go run ./cmd/tei validate -workspace reference/workspace
```

詳しい確認手順と参照用作業領域の範囲は[使い始める](getting-started.md)を参照してください。ここに手順を載せたことは、公開候補や最新のコミットで試験に合格したという意味ではありません。

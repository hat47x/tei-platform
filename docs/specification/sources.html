資料・出典と仕様の追跡

第三者がTEIの現在の仕様と設計判断を追える範囲に絞って、参照先を整理します。

追跡の原則

現在のProduct Requirements、採用済みArchitecture / ADR、実装、Reference、Evidenceを優先します。調査過程や作業上のやり取りそのものは、仕様の根拠として公開文書へ持ち込みません。

TEI内の主要な正本

種類主な参照先役割
ProductValue / Vision / Principles何を価値とし、何を目指すか。
RequirementsTEI Product Requirements満たすべき要求。
ArchitectureArchitecture / Business System Design責務境界と意味上の制約。
Planning / EvidenceMaster Plan / Acceptance Scenario Traceability能力到達点、受入条件、未解決事項。
Implementationtei-platform Repository実装とテストによる現在の実証状態。

外部の公開知見

TEIでは、業務システム設計、モデル駆動・メタデータ駆動設計、実行可能仕様、複数Target、AI支援authoring等の公開知見を必要に応じて参照します。X-TEA／XEADを含む既存の手法やソフトウェアから得た着想もありますが、TEIは独立したプロジェクトであり、公式な系譜・互換性・優劣を示すものではありません。

外部参照は設計上の問いを考える材料として扱い、TEIの仕様はTEI自身のRequirements、Architecture、Reference、ADR、Evidenceで説明します。

引用・再利用

第三者の文書、ソースコード、モデル、データ等は、それぞれの公開条件・利用条件に従います。利用条件を確認できない内容をTEI Repositoryへ複製・再配布しません。

仕様の状態

この仕様ガイドには採用済みの境界と評価中の候補が含まれます。現在地はRepositoryの要求・ADR・実装・Reference・Evidenceを優先してください。

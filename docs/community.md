# コミュニティと参加について

TEIはMITライセンスで公開します。

TEIへの参加は、コードを書くことに限りません。実際に試した結果、設計や運用で得た知見、既存システムに当てはめた際の問題点、再利用できる業務知識を共有することも重要な参加です。

利用者に、保守担当者になることや継続的なコード貢献を求める運営にはしません。

たとえば、次のような報告や意見を歓迎します。

- 既存の業務システムへ当てはめたときに表現しにくかったこと
- 他のローコード基盤、ワークフローエンジン、データベースツールなどとの比較
- 長期運用や移行で問題になりそうな境界
- AIと人が共同で設計する際に分かりにくかった概念
- 参照用ワークスペース（Reference Workspace）では扱えていない実際の業務要件
- TEIの概念や文書について、自然に理解できた点・できなかった点

まずは自由に試せることと、必要に応じて知見を共有しやすいことを重視します。

コード変更を提案する場合の基本的な進め方は [CONTRIBUTING.md](../CONTRIBUTING.md) を参照してください。

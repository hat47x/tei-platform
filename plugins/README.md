# プラグイン

このディレクトリは、TEIの標準プラグインをサブプロジェクトごとに管理するための入口です。**現時点では既存のプラグイン実装や参照データをここへ一括移動していません。**

TEIでは、標準機能もできる限り共通の契約を通じて提供します。言語処理、生成器、認証、データベース接続に加え、ブラウザやデスクトップなどの実行先固有の機構も、原則としてプラグインの対象です。

## 独立構築の参照例

[処理実行プラグインの参照サブプロジェクト](reference-process-executor/README.md)では、現行のプロセス呼出し方式と互換のある最小実装を、TEI内部のGoパッケージに依存せずに構築・試験します。**参照実装であり、製品用プラグインや正式な新契約ではありません。** ほかの標準プラグインが移行済みであることも意味しません。

[二つの論理プラグインを一つの実行ファイルにまとめる参照例](../tools/reference-plugin-bundle/README.md)では、ソース単位と成果物が一対一でない場合の識別・呼出し・拒否を検証します。独立した二つのプラグインを一つのGo成果物に静的結合し、それぞれの機能IDと来歴を確認する試験です。

## 新しいサブプロジェクトの案内

独立したプラグインを追加するときは、原則として`plugins/<プラグイン名>/`にまとめ、`README.md`で責務、提供する契約、依存先、構築・検証方法を説明します。契約の正本や生成物を重複して保管しません。言語ごとの標準的な構成と既存の構築契約を利用し、不要な設定形式を増やさないようにします。

プラグインの識別子は、サブプロジェクトのパス、Goモジュール名、配布物や実行ファイル名と一対一とは限りません。複数のプラグインをまとめて構築する方式と、実行先ごとに異なる成果物を作る方式の両方を認めます。

設計上の判断は[ADR-0033](../plan/adr/0033-core-and-plugin-subprojects.md)と[ADR-0032](../plan/adr/0032-composition-kernel-replacement.md)を参照してください。ここには説明を置き、開発エージェント向けの一般的な指示を`AGENTS.md`として複製しません。

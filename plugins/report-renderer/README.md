# 参照用の帳票整形プラグイン

ホストは`SelectBounded`で正の件数・出力バイト上限を指定できます。通常の選択は1万行・8MiBを上限とし、JSONのエスケープやCSVの見出し・引用を含む実際の出力サイズを検査します。超過時は`ErrReportBudget`を返し、部分文書を返しません。これは業務上の最大件数ではなく、ホストの資源予算です。全工程の最大メモリ使用量や大規模処理の性能は未検証です。

受注明細の文字列行からCSVまたはJSONの文書を作る、静的に結合する実装です。契約は`renderer.go`の`Contract`、入力は`[]Row`、出力は`Document`です。同じ契約に対して`report-csv`と`report-json`をホストが選びます。契約の形状は参照用Go APIの識別であり、外部実装の適合証明ではありません。

データ取得、認証・認可、保存先の決定、ファイル保存は担当しません。CSVでは表計算ソフトによる式の解釈を防ぐため、危険な先頭文字を持つセルに引用符を加えます。JSONは元の文字列を保持します。数値の再計算や業務ルールの再実装は行いません。

ルートのGoモジュールから`go test ./plugins/report-renderer`で検査できます。参照ホストへの接続は[Issue #1223](https://github.com/hat47x/tei-platform/issues/1223)に記録した未統合の検証ブランチにあり、mainにはまだありません。独立配布、PDFの表示品質、本番帳票への適合は未確認です。
